# LionSQL v0.90.0-beta0 릴리즈 노트 (`notes/RELEASE_NOTES_v0.90.0-beta0.ko.md`)

> - **릴리즈 일자**: 2026-10-19
> - **버전**: `v0.90.0-beta0`
> - **마일스톤 주제**: **기능 동결 기준선 (Feature Freeze Baseline), 웹 스튜디오 완성, 글로벌 메모리 거버너 및 단일 바이너리 CLI 통합**

---

## 1. 릴리즈 하이라이트 개요

LionSQL `v0.90.0-beta0`은 1.0 프로덕션 릴리즈를 향한 공식 **기능 동결 기준선(Feature Freeze Baseline)**을 확립한 마일스톤입니다. 모든 서버 및 운영 도구를 100MB 미만의 단일 독립형 정적 바이너리로 통합하고, 프로덕션급 웹 관리 스튜디오를 내장하며, 폭주 쿼리를 차단하는 글로벌 메모리 거버너와 보안이 강화된 무의존성 REST API를 완성했습니다.

- **단일 자립형 통합 CLI (`cmd/lionsql`)**: 서버 데몬 및 운영 도구를 단일 실행 파일로 통합하고 직관적인 서브커맨드(`serve`, `start`, `stop`, `restart`, `status`, `doctor`, `backup`, `restore`, `migrate`, `sql`) 지원.
- **프로덕션 웹 스튜디오 스위트 (`UI-DDL-1`, `UI-REALTIME-1`, `UI-DATA-1`, `UI-LOGS-1`)**:
  - DDL 시각적 컬럼 추가 모달.
  - 200건 원형 링 버퍼 기반 실시간 CDC / SSE 스트림 뷰어 (일시정지/재개/검색).
  - 다중 행 일괄 작업(삭제, CSV/JSON 내보내기) 및 외래키 인터랙티브 셀 내비게이션.
  - 마이크로초 단위 지연 시간 프로파일링을 지원하는 HTTP 요청 활동 로그 뷰어.
- **글로벌 메모리 거버너 & 서킷 브레이커 (`MEM-1`)**: 물리 RAM의 최대 70% 동적 할당 및 쿼리별 메모리 상한(`work_mem: 64MB`)을 두어, OS OOM-Killer 대신 설명 가능한 SQLSTATE 오류로 폭주 쿼리를 안전하게 차단.
- **HTTP REST & 웹 관리 포트 8090 보안 강화 (`HTTP-1` ~ `HTTP-4`)**: 무의존성 글로벌 CORS, 투명 Gzip 압축(전송량 77% 절감), 요청 바디 32MB 상한 가드 및 37개 시나리오 전수 검증 통과.
- **엔터프라이즈 매뉴얼 전면 개편**: 사용자 매뉴얼(1,307라인), 레퍼런스 매뉴얼(1,770라인), 트랜잭션 성능 가이드, 웹 스튜디오 매뉴얼 공식 발행.

## 2. 세부 변경 사항

### 2.1. 통합 CLI 및 자립형 프로세스 수명주기
- 인자 없이 `lionsql` 실행 시 포그라운드 서버 기본 구동 지원.
- 데몬 프로세스 제어, 자동 상태 진단(`doctor`), 기본 비밀번호 사용 시 보안 경고 배너 출력.
- `pkg/config/version.go`에 릴리즈 버전 단일 진실 공급원(SSOT) 확립.

### 2.2. 웹 스튜디오 관리 UI/UX 현대화
- 브라우저 블로킹 `alert()` 13개를 세련된 애니메이션 토스트(Toast) 알림으로 전면 교체.
- 모바일 및 분할 화면을 지원하는 반응형 레이아웃(`@media (max-width: 900px)`) 및 햄버거 메뉴 적용.
- 오작동 방지를 위한 정확한 테이블명 타이핑 기반 테이블 드롭(Drop Table) 확인 모달 구축.
- PocketBase 수준의 스키마 인지형 개발자 API 프리뷰 모달(cURL, Fetch, Python, Go, `lionsql.js` 공식 SDK 탭) 탑재.
- WCAG AAA 대비율을 만족하는 다크/라이트 테마 전환기 도입.

### 2.3. HTTP 서버 보안 및 하드닝
- 사전 비행(Preflight) 빠른 응답을 지원하는 제로 의존성 전역 CORS 미들웨어.
- `sync.Pool` 기반 버퍼 재사용 Gzip 압축 (198KB -> 45KB 절감).
- 보안 헤더 강제: `nosniff`, `SAMEORIGIN`, `strict-origin-when-cross-origin`.

### 2.4. 안정성 및 셧다운 레이스 방지
- 서버 종료 시 유예 드레인 및 원자적 세션 가드를 도입하여 WiredTiger 커넥션 조기 해제에 따른 `SIGSEGV(addr=0xad0)` 크래시 원천 차단.
- 장수명 SSE 스트리밍 엔드포인트 타임아웃 예외 처리로 영구 연결 유지.
- 가상 카탈로그의 정규 프로토콜 데이터베이스(`postgres`, `master`) 표준화.
