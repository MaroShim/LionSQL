# LionSQL v0.90.0-beta1 릴리즈 노트 (`notes/RELEASE_NOTES_v0.90.0-beta1.ko.md`)

> - **릴리즈 일자**: 2026-10-20
> - **버전**: `v0.90.0-beta1`
> - **마일스톤 주제**: **프로덕션 보안 가드레일, SQL 엄격한 NULL 전파 및 43대 엔진 정합성·동시성 결함 완치**

---

## 1. 릴리즈 하이라이트 개요

LionSQL `v0.90.0-beta1`은 **프로덕션 보안 가드레일 확립, SQL 표준 3치 논리(Three-Valued Logic) 준수, 타입 승격 래티스 구축, 그리고 VDBE 가상머신·DML 실행기·스토리지 전반의 43대 핵심 결함 완치**에 집중한 대규모 안정화 릴리즈입니다.

- **프로덕션 슈퍼유저 보안 가드레일 (`PROD-SEC-1`)**: 기본 관리자 비밀번호(`1234567890`)를 유지한 채 외부 인터페이스(`0.0.0.0` 또는 공인 IP)로 바인딩을 시도할 경우 서버 기동을 즉시 차단하는 안전 가드 적용.
- **엄격한 SQL NULL 전파 데코레이터 (`SQL-STRICT-NULL-DECORATOR-1`)**: 모든 내장 함수 및 스칼라 연산자에 표준 SQL 3치 논리를 적용하여 임의의 기본값 대체 현상을 제거.
- **통합 타입 승격 래티스 (`STORAGE-TYPE-PROMOTION-LATTICE-1`)**: 150라인 이상의 이기종 타입 비교 코드를 단일화된 자동 강제 변환 엔진(`storage.CoerceBinaryValues`)으로 대체.
- **중앙 집중식 인조 행 식별자 추상화 (`STORAGE-SYNTHETIC-PK-ABSTRACTION-1`)**: 산재되어 있던 인조 기본키(`_row_id`, `_dt_row_id`, `_cte_row_id`)를 단일 추상화로 정돈.
- **43대 코어 커널 결함 완치**: Simple CASE 구문 복원, FROM 없는 스칼라 서브쿼리 패닉 방지, MERGE 트랜잭션 동기화, 재시작 시 뷰/프로시저 영구 저장 등 코어 결함 전수 해결.

## 2. 세부 변경 사항

### 2.1. 보안, 인증 및 브랜드 단일화
- 기본 비밀번호 유지 상태에서 외부 공개 바인딩 시 기동 즉시 중단.
- 클라이언트 SDK(`lionsql.js`), 프로토콜 배너(PGWire, TDS), 시스템 정보 전반을 LionSQL로 통합.
- RBAC 역할 검증 및 명시적 거부(`DENY`) 우선순위 확립.

### 2.2. VDBE 가상머신 및 T-SQL 파서 결함 완치
- `CASE expr WHEN val THEN ...` 단순 CASE 구문 및 이기종 타입 비교 복원.
- `(SELECT 42)`와 같은 FROM 절 없는 스칼라 서브쿼리 실행 시의 nil 역참조 패닉 완치.
- INSERT 시 생략된 컬럼에 대해 스키마 기본값(`GETDATE()`, `NEWID()`, 리터럴) 자동 주입.
- 브래킷(`[col]`) 및 대소문자 변형 식별자에 따른 UPDATE 누락 방지.
- 단일 컬럼 스캔 시 복합 인덱스가 오인 선택되는 결함 차단.

### 2.3. DML 실행기, MERGE 및 파생 테이블 정합성
- `MERGE ... INSERT` 실행 시 테이블 및 세션의 IDENTITY 상태 동기화.
- `MERGE WHEN NOT MATCHED BY SOURCE` 실행 시 방금 새로 삽입된 행이 자가 삭제되는 결함 해결.
- `APPLY` 절 토큰 치환 시 정규식 대신 식별자 기반 토큰 치환으로 리터럴 오염 방지.
- `PIVOT` 카테고리 매칭 결과가 없을 때 `NULL` 대신 SQL 표준인 `0` 반환.

### 2.4. 스토리지 대소문자, 타입 강제 변환 및 PITR 복구
- 제네릭 대소문자 무시 맵(`CIMap`) 도입으로 테이블 및 인덱스 조회 대소문자 중립성 보장.
- 서버 재시작 시 뷰, 프로시저, 트리거가 유실되지 않도록 `catalog_objects.json` 원자적 파일 동기화.
- Point-in-Time Recovery 및 WAL 재생 시 DDL 오류 억제(`_ = err`) 제거 및 실패 시 즉각 롤백.
- `storage.Value.Compare`에서 Int와 Float 간 자동 수치 비교 지원.
