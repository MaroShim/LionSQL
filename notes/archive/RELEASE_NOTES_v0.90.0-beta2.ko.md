# LionSQL v0.90.0-beta2 릴리즈 노트 (`notes/RELEASE_NOTES_v0.90.0-beta2.ko.md`)

> - **릴리즈 일자**: 2026-10-21
> - **버전**: `v0.90.0-beta2`
> - **마일스톤 주제**: **토큰 기반 DML 컴파일러 아키텍처, 핫패스 7대 성능 최적화 및 비키퍼 스튜디오(Beekeeper Studio) 엔터프라이즈 연동**

---

## 1. 릴리즈 하이라이트 개요

LionSQL `v0.90.0-beta2`는 기존의 취약한 정규 표현식을 전면 폐기하고 **토큰 기반 단일 패스 DML 컴파일러(`ARCH-DML-1`)**를 도입하여 아키텍처를 혁신하고, **핫패스 제로 할당 최적화 7종(`VPERF-2` ~ `VPERF-14`)**, 그리고 엔터프라이즈 GUI 도구인 **비키퍼 스튜디오(Beekeeper Studio) 완벽 연동** 및 웹 스튜디오 실시간 모니터링 대시보드를 구축한 릴리즈입니다.

- **토큰 기반 단일 패스 DML 컴파일러 (`ARCH-DML-1`, `ARCH-LEX-1`)**: 8개의 취약한 정규식(`reDml*`)과 300라인 이상의 수동 파싱 루프를 토큰 인지형 파서와 통합 어휘 스캐너(`pkg/sqlutil`)로 대체. 55개 특성화 테스트로 100% 안전성 입증.
- **핫패스 제로 할당 성능 최적화 7종 (VPERF 트랙)**:
  - Autocommit 쿼리 시 `ClientSession.Session` 재사용으로 WiredTiger CGO 세션 유지.
  - MemEngine 역방향 외래키 캐시(`fkCache`) 구축으로 $O(1)$ 빠른 검증.
  - 동적 TDS 패킷 프레이밍(최대 32KB) 및 UTF-16LE 직접 직렬화.
  - `PlanCache.GetOrCompile` 문자열 키 기반 RLock 패스트패스 도입.
  - 트리거 미사용 테이블 대상 불필요한 행 맵 할당 전면 우회.
- **비키퍼 스튜디오(Beekeeper Studio) 엔터프라이즈 호환 (`BUG-TDS-BEEKEEPER-RPC-STATEMENT-1`)**: `node-mssql` 드라이버의 `@statement` 매개변수 명칭 불일치 시 서수 기반 위치 폴백을 지원하여 연결 시 핸드셰이크 오류 완전 해소.
- **웹 스튜디오 실시간 개요 모니터링 대시보드 (`UI-OVERVIEW-1`, `UI-14`)**:
  - 엔진 상태, 활성 세션, 실시간 초당 트랜잭션(TPS), 서버 가동 시간 카드를 포함한 개요 탭 및 자동 갱신(5s, 10s, 30s, 60s) 지원.
  - 4개 영역으로 구조화된 좌측 내비게이션 바.
- **듀얼 포맷 CLI 버전 출력 (`CLI-VERSION-1`)**: 상세 빌드 보고서(`--version`) 및 포그라운드 기동 시의 1줄 요약 배너 지원.

## 2. 세부 변경 사항

### 2.1. 파서 아키텍처 및 어휘 스캐너 단일화
- INSERT, UPDATE, DELETE 구문을 단일 AST로 통합 파싱하여 문자열 리터럴 내부의 `WHERE` 키워드 오작동(`REV-ENG-006`) 완치.
- 중첩 괄호 추적 및 산술 연산자 분리를 `pkg/sqlutil`로 일원화.

### 2.2. 버티컬 성능 최적화 (VPERF 트랙)
- Autocommit 쿼리 메모리 할당 제거로 WiredTiger CGO 세션 및 커서 풀 유지.
- 자식 외래키 참조가 없는 부모 테이블 변경 시 테이블 풀 스캔 방지.
- `execUpdateWhere` 및 `execDeleteWhere` 루프 외부로 스키마 조회 호이스팅.
- `INSERT ... ON CONFLICT` 실행 시 보조 인덱스 탐색 활용.

### 2.3. 와이어 프로토콜, COPY 및 인증 결함 완치
- 기본 관리자 계정에 대한 비밀번호 무조건 우회 취약점 제거 (`BUG-AUTH-ADMIN-PW-BYPASS-1`).
- `COPY IN` 및 `COPY OUT`을 활성 트랜잭션에 직결하여 롤백 원자성 보장.
- PGWire `$1` 파라미터가 `$10` 등 다자리수를 오염시키던 결함 수정.
- 유효하지 않은 숫자/날짜 COPY 입력 시 기본값 대체 대신 구조화된 문법 오류 반환.

### 2.4. 스토리지 안정성 및 세션 관리
- WiredTiger 백그라운드 동기화 루프에 5분 주기 세션 리셋을 추가하여 60분 유휴 세션 경고 해소.
- 세션 격리 임시 테이블(`__temp_*`, `#*`)의 디스크 스냅샷 및 WAL 유출 차단.
- 내림차순 인덱스 스캔 역방향 이터레이터(`IndexScanDesc`) 구현.
