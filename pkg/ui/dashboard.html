Records CRUD & Filtering

            
// 1. Paginated & Filtered Query

await client.collection('customers').delete(newRow.id);

              STANDALONE
              
Autonomous Single-Node Engine

            

            

              High-Availability (HA) replication streaming is not enabled on this instance. LionSQL is currently running as an autonomous standalone database with local ACID durability.
            

            

              
How to Start High-Availability Replication Topology:

              
# 1. Primary Node (Single Writer)
lionsql serve --http=127.0.0.1:8090 --pg=127.0.0.1:5433 --tds=127.0.0.1:1433 --rep-role=primary --rep-node=primary-1

# 2. Secondary Replica Node (Read-Only Scale-Out)
lionsql serve --http=127.0.0.1:8091 --pg=127.0.0.1:5434 --tds=127.0.0.1:1434 --rep-role=replica --rep-node=replica-1 --replica-of=http://127.0.0.1:8090

            

          

        

      


      
      

        
High Availability Architecture Invariant: 1-Writer Multi-Reader Topology

        LionSQL prioritizes vertical scale-up hardware saturation with 1-Writer Multi-Reader physical WAL replication. Readers never block writers and writers never block readers. All write transactions execute strictly on the authoritative Primary node, while Replicas stream and replay physical WAL records with sub-millisecond latency.
